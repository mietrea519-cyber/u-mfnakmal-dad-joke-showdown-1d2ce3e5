# Dad Joke Showdown

A tiny Node 22 TypeScript entry for the Dad Joke Showdown. Running `main.ts` writes one original dad joke — a thermostat standoff that ends in some very cool parenting — to `/output/entry.txt`, keeping it short, clean, and ready to be delivered across the dinner table.
